# PhraseNest

RedditやEngooなどのWebページで選択した英文をその場で翻訳し、英文・訳・単語・熟語をSupabaseへ保存して復習する個人向け英語学習アプリです。

## 構成

「今日の復習」の学習記録カレンダーでは、最近8週間の英文保存と復習を日本時間で表示します。日付を押すと内訳を確認できます。英文1件＋同じ日の復習語（重複を除く）の数で色が変わり、「忘れた」も学習として数えます。既存の `sentences` と `review_logs` を読み取るため、カレンダー用のSQLやAI・翻訳APIの呼び出しは不要です。保存内容・復習履歴を削除すると該当する記録も集計から外れます。

- `app/`: PC・スマホ対応の復習ページ
- `extension/`: 呼び出したWebページで動くChrome拡張機能
- `supabase/migrations/`: 保存データ、重複判定、復習処理
- `supabase/functions/`: クラウド翻訳と任意のAI解説

## APIを使わない英作文の練習

公開ページの「メニュー → 英作文の練習」から開けます。保存済みの表現を1〜3個選び、用意したお題で2〜4文を書き、「作文と指示文をコピー」を押してChatGPTなどへ貼り付けます。返ってきた添削・修正文をアプリへ貼り付け、保存してください。表現に合うお題が欲しいときは「お題作成用の指示文をコピー」も使えます。AI・翻訳APIをこの画面から呼ぶことはありませんが、外部AIに貼り付けたときはそのサービスの利用枠を消費します。

作文は既存の `sentences` に入手元「英作文」としてクラウド保存し、お題・対象表現・添削は区切り付きのメモとして残します。日本語は任意です。最初の保存後も添削を追加して同じ記録を更新でき、元の作文・元の単語の説明・登場回数・復習予定は変えません。追加SQLは不要です。作文画面の履歴（最近10件）と「保存内容 → 英文」で見返せます。

下書きはページ内の画面切り替えでは保持しますが、端末やクラウドへ自動保存はしません。未保存の状態でページを閉じる際に警告します。保存失敗時は入力を残し、「次の練習を始める」では未保存の内容を消す前に確認します。AIへ送る指示文には選択した表現だけを含め、意味は各250文字・コアイメージは各600文字までに絞ります。元のメモの全文は保存時にそのまま残します。

## ローカルで復習ページを確認

```powershell
npm install
npm run dev
```

Supabase未設定時は初回接続画面が表示されます。

初回は画面上でProject URLとPublishable keyを入力できます。Googleログイン前に、画面に表示されるローカルURL（例：`http://localhost:3000/`）をSupabaseのAuthentication > URL Configuration > Redirect URLsへ追加してください。

## Supabaseを接続

1. Supabaseで新しいプロジェクトを作成します。
2. SQL Editorで `supabase/migrations/0001_initial_schema.sql` を実行します。
3. Authentication > ProvidersでGoogleを有効にします。
4. `.env.example` を `.env.local` としてコピーし、Project URLとPublishable keyを設定します。
5. Google Cloud Translationを有効にし、Edge FunctionのSecretに `GOOGLE_TRANSLATE_API_KEY` を設定します。
6. AI解説を使う場合だけ `OPENAI_API_KEY` を設定します。
7. `translate` と `explain` のEdge Functionをデプロイします。

秘密鍵やOpenAI APIキーを `.env.local` やChrome拡張機能へ入れないでください。

## Chrome拡張機能を追加

1. Chromeで `chrome://extensions` を開きます。
2. デベロッパーモードをオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」から `extension` フォルダーを選びます。
4. 自動で開く設定画面にSupabaseのProject URLとPublishable keyを入力します。
5. 表示された拡張機能用リダイレクトURLを、Supabaseの許可済みRedirect URLへ追加します。
6. Googleで一度ログインします。

別のPCでも同じ手順で利用できます。現在はChromeウェブストア未公開のため、GitHubからプロジェクトをダウンロードし、その中の `extension` フォルダーを読み込んでください。パッケージ化されていない拡張機能のIDはPCごとに変わる場合があるため、新しいPCの設定画面に表示されたリダイレクトURLもSupabaseへ追加します。Project URLとPublishable keyは元のPCと同じものを使い、同じGoogleアカウントでログインします。

RedditやEngooなどの通常のWebページで英文を選択し、`Ctrl + Shift + Y` を押すと翻訳小窓が開きます。Chromeの拡張機能ショートカット画面からキーを変更できます。

バージョン0.9.3からは、サイトの追加設定は不要です。`activeTab`（呼び出したタブへの一時的なアクセス）と `scripting` を使い、呼び出したときだけ画面の処理を読み込みます。全サイトを常時読み取る権限や自動起動は追加していません。保存時には元ページのURL・タイトルを記録し、Reddit以外を誤ってsubredditとして扱わないようにしています。Chromeの設定ページ・ウェブストア・画像内の文字・別サイトの埋め込み枠などは対象外です。

反映は `chrome://extensions` のPhraseNestを再読み込みし、利用するページも再読み込みしてください。Chrome右上のPhraseNestアイコンから「このページでPhraseNestを開く」でも使えます。英文を選択していない場合は、翻訳せずページ内のメニューだけを開きます。公開復習ページとSupabaseの変更作業は不要です。

英文を選択していない場合も、`Ctrl + Shift + Y` でメニューを開けます。Chrome右上のPhraseNestアイコンからは、Reddit以外のページでも保存した英文・単語帳・学習メモ・復習へ直接移動できます。

Redditの小窓とChromeアイコンの入口も「入力」「今日の復習」「保存内容」「メニュー」に整理しています。「保存内容」は公開ページで最後に見た英文・語句・メモの種類を開きます。単語・熟語、学習メモ、整理、拡張機能の設定はメニュー内にあります。小窓の文字サイズ・サイズリセットもメニュー内へ移しました。メニューは外側のクリックまたはEscで閉じられ、メニューが閉じているときのEscで小窓を閉じます。改修反映には拡張機能を再読み込みした後、Redditのページも再読み込みしてください（バージョン0.9.1）。

翻訳小窓の「ワイド」で英文と訳を左右に並べられます。幅のモード・文字サイズ・小窓の位置は、このPCのChromeに記憶します。復習ページには保存内容全体の検索と文字サイズ切り替え、単語帳にはメモあり・登場回数の絞り込みと並び替えがあります。

小窓の四隅をドラッグすると、幅と高さを調整できます。通常の最小サイズは400×400pxで、小さな画面では画面内に収まる大きさを優先します。幅が狭いときは縦並びにし、内容は小窓内でスクロールできます。「サイズをリセット」で標準幅・自動の高さ・右上の位置に戻します（訳・メモ・文字サイズは変えません）。サイズもこのPCのChromeに記憶します。角の操作部分をTabキーで選び、矢印キーで10pxずつ、Shift＋矢印キーで40pxずつ調整することもできます。

訳やメモは自動保存ではありません。小窓には「未保存」「保存済み」「保存後の変更あり」を表示します。変更せずに同じ保存ボタンを連続で押すことは防いでいますが、保存後に編集して小窓から再保存すると、従来どおり別の英文記録が追加されます。既存の記録を修正する場合は、上部の「保存内容」からその記録の「編集」を使ってください。

改修後は `chrome://extensions` のPhraseNestで再読み込みボタンを押し、Redditのページも再読み込みしてください。

## 自分で英文と訳を入力して保存

復習ページの主な入口はPC・スマホ共通で「入力して保存（スマホは入力）」「今日の復習」「保存内容」「メニュー」の4つです。「保存内容」で英文・単語／熟語・学習メモを切り替えられ、最後に見た種類をこのブラウザーに記憶します。整理・設定は「メニュー」から開きます。拡張機能などの既存の英文・単語・メモへの直接リンクもそのまま使えます。

復習ページやChromeのPhraseNestメニューの「入力して保存」を開きます。PC・スマホで使えます。英文と日本語訳を自分で入力・貼り付けすれば、翻訳を使わずに保存できます。使う場面のメモ、入手元、任意の参照URLも残せます。

「英語を日本語に翻訳」「日本語を英語に翻訳」を押したときだけ、Google翻訳を使います。既存の月450,000文字の上限と共通で、保存ボタンでは翻訳もAIも呼びません。上限到達・翻訳エラー時も、自分で訳を入力して保存できます。

単語・熟語の意味は手入力です。「語句を追加」で必要なものだけ登録できます。英文全体を1つのフレーズとして追加しても構いません。語句の重複判定・登場回数・復習は従来の仕組みを使います。0004のSQLを適用すると、同じ単語の異なる意味・コアイメージ・メモは元の内容の下に区切り線と【追記】を付けて保存します。空欄や同じ説明は重ねて追加しません。

既存の単語に説明だけを追加する場合は「保存内容」→「単語・熟語」→「追記」を使います。「編集」は欄全体の修正として残しています。準備と確認方法は [単語の説明の追記ガイド](docs/vocabulary-append-guide.md) を参照してください。新しいSQL `supabase/migrations/0004_append_vocabulary_details.sql` の1回の実行が必要です（記録の削除・既存データの書き換えはしません）。

入力は画面を切り替えても保持しますが、自動保存ではなく、ページの再読み込みをまたぐ下書き保存はしません。保存に成功したときだけ英文・訳・メモ・語句・参照URLを空にし、入手元を初期値に戻します。保存完了の表示と英文一覧へのリンクは残し、入力画面を開いていれば英文欄へ入力位置を戻します。失敗時は入力を保持し、保存中の連打と空欄のままの再保存は防ぎます。次の入力にも未保存の警告が働きます。保存済みの内容は英文一覧・単語帳の「編集」で修正します。

翻訳はGoogle Cloud Translationを優先し、月450,000文字で停止します。Google翻訳へ接続できない場合は、Chrome内蔵翻訳へ自動で切り替わります。単語・熟語候補はまとめて翻訳し、通信回数を抑えています。よく使われる句動詞・熟語・会話表現は拡張機能内の一覧と照合し、`figure out`、`figured out` のような活用形も候補にします。
