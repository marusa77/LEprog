# PhraseNest

RedditやEngooなどで読んだ英語を、その場で調べて保存し、PC・スマホで復習する英語学習アプリです。

PC版Chromeの拡張機能、復習用のWeb画面、Supabaseの保存先を組み合わせて使います。自分のSupabaseプロジェクトとWeb画面の実行・公開環境を用意する構成です。

## 主な機能

| 入口 | できること |
| --- | --- |
| Chromeの翻訳小窓 | 選択した英文の翻訳、語句候補の表示、訳・メモ・語句の保存、英文・質問文のコピー |
| 入力して保存 | 英文・訳と知識ノートの作成、必要なときだけ英日・日英翻訳 |
| 今日の復習 | 単語・熟語の意味、コアイメージ、例文の確認と復習記録 |
| 保存内容 | 英文・語句・学習メモの一覧、検索、編集・追記、英文の並び替えと復習 |
| メニュー | 英作文の練習、未整理分の書き出しと確認、設定 |

保存内容では、英文・単語／熟語・学習メモを切り替えられます。同じSupabaseとGoogleアカウントを使うことで、PC・スマホから同じ記録を確認できます。

例文なしで文法や使い分けを整理する「知識ノート」は、「入力して保存」で作成し、「保存内容 → 学習メモ」で閲覧・編集できます。タイトル・本文で保存し、任意のひな形、検索、「あとで確認する」目印を使えます。英文・語句に付けた既存のメモとは別に管理します。

## 導入と利用アカウント

初回はSupabaseとGoogleログインを設定し、利用するアカウントのUser UID（識別番号）を許可一覧へ登録します。Googleでログインできても、許可されていないアカウントでは学習データや翻訳機能を使えません。

UUIDを指定する操作は利用許可の**追加**です。Aを許可した後でBを追加すると両方が使え、Aの許可は自動では外れません。保存データはアカウントごとに別で、自動的に移行・共有されません。

同じアカウントを別PCで使うだけなら、UUIDを変更する必要はありません。設定済み拡張機能のZIPを使えば、各PCでの接続情報の貼り付けを省けます。戻り先URLは管理者が一度登録し、各PCでは同じZIPを読み込んでGoogleでログインします。

初回設定、許可一覧の確認・追加・解除、アカウントの切り替えは[利用アカウントの設定](docs/setup.md#account-access)を、設定済みZIPの作成は[導入・設定ガイド](docs/setup.md)を参照してください。自分で運用する場合は、自分のSupabaseと翻訳サービスを用意します。

## 基本的な使い方

### PCで英文を取り込む

1. Webページで英文を選択します。
2. `Ctrl + Shift + Y`でPhraseNestの小窓を開きます。
3. 訳・メモを確認し、保存したい語句にチェックします。
4. 「英文と語句を保存」を押します。

サイトごとの登録は不要です。英文を選択せずに呼び出せば、保存内容・復習へのメニューを開けます。Chrome右上のPhraseNestアイコンからも操作できます。

熟語・会話表現の候補は既定のリストなどに基づくため、すべてを自動検出するものではありません。必要な語句は手動で追加できます。

「英文をコピー」「質問文をコピー」を使えば、ChatGPTなどへ自分で貼り付けて、意味やコアイメージを調べられます。コピーだけでは外部AIへ送信しません。

### 単語・熟語を復習する

「今日の復習」で意味を思い出し、「答えを見る」で説明・例文を確認します。「忘れた・あいまい・覚えていた」を選ぶと、次の復習予定が更新されます。

意味・コアイメージ・自由メモは「保存内容」で見返せます。「追記」は元の説明を残して下に追加し、「編集」は欄全体を修正します。

### 英文を並び替えて復習する

「保存内容 → 英文」で「最新順・ランダム・復習シャッフル」を切り替えられます。復習シャッフルでは、未復習・長く読み直していない英文を出やすくします。

英文ごとの「少なめ・通常・多め」で、出やすさも調整できます。「少なめ」でも完全には除外せず、設定変更は次のシャッフルから反映します。

5・10・20件を選び、重複なしで1件ずつ読み直せます。「読み直した」で履歴を保存し、「今回はスキップ」は記録しません。関連する単語の学習状態は変更しません。

### 自分で入力する・英作文を練習する

「入力して保存」では、英文と自分で用意した日本語訳、メモ、必要な語句を登録できます。保存成功後は入力欄が空になり、続けて登録できます。失敗時は入力を残します。

「メニュー → 英作文の練習」では、保存した表現を使って作文し、外部AIへの指示文をコピーできます。添削結果は自分で貼り付けて保存します。この画面からAI・翻訳APIは呼びません。

### 整理・学習記録を確認する

「メニュー → 整理」で未整理分をJSONに書き出し、外部で整理した結果を読み込みます。候補を確認してから反映する方式です。

「今日の復習」のカレンダーには、最近8週間の保存・追記、英文／語句／ノートの復習、翻訳で調べた日を日本時間で記録します。英文10件の復習も1件ずつ反映します。同じ対象の同じ行動は1日1件とし、学習に触れた日の目安にできます。

## 対応環境と注意点

- 拡張機能はPC版Chrome 138以降に対応しています。Chromeウェブストアには未公開です。スマホではWeb画面での閲覧・復習・入力を利用します。
- Chromeの設定ページ・ウェブストア・画像内の文字などは取り込み対象外です。
- 訳・メモ・作文は自動保存ではありません。小窓で保存後に編集して再保存すると別の英文記録になります。既存の英文の修正は「保存内容 → 英文 → 編集」を使います。
- 下書きや英文復習の途中位置は、ページの再読み込み後には復元しません。保存済みの記録はSupabaseに残ります。
- Google翻訳のアプリ内上限は利用者ごとに月450,000文字です。請求全体を止める仕組みではなく、料金は各サービスの設定・利用量に依存します。
- 外部AIへ貼り付けた内容は送信先サービスに渡り、そのサービスの利用枠を使います。秘密情報を含めないよう確認してください。

## 構成

- `app/`：PC・スマホ用のWeb画面とSupabaseへの接続処理
- `extension/`：Chromeの翻訳小窓・設定・起動処理
- `supabase/migrations/`：保存データと処理の設定
- `supabase/functions/`：翻訳・任意のAPI解説のサーバー側処理
- `docs/`：導入・利用ガイド
- `tests/`：自動テスト
