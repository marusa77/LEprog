# 詳しい使い方

アプリ上部、または「メニュー → 使い方」から基本の手順を確認できます。拡張機能の小窓・アイコンのメニューからも開けます。普段の画面では補足を必要な場所に絞り、詳しい説明は開閉できる領域にまとめています。

## 英文を取り込む

PC版Chromeで英文を選択し、`Ctrl + Shift + Y`を押します。サイトごとの登録は不要です。Chrome右上のPhraseNestアイコンの「このページでPhraseNestを開く」からも呼び出せます。

英文を選択していない場合は、翻訳せずメニューを開きます。ショートカットは`chrome://extensions/shortcuts`で変更できます。

表示された訳やメモを確認・編集し、保存したい語句にチェックして「英文と語句を保存」を押してください。熟語・句動詞・会話表現の候補は既定のリストなどに基づくため、すべてを自動検出するものではありません。必要な語句は英文から選択するか、入力して追加できます。

元ページのURL・タイトルも保存します。Chromeの設定ページ・ウェブストア、画像内の文字、別サイトの埋め込み枠などは取り込み対象外です。

### コピーして外部AIに質問する

- 「英文をコピー」：元の英文だけをコピーします。
- 「質問文をコピー」：英文と、意味・重要な語句・コアイメージの説明を頼む指示文をコピーします。
- 語句の「質問をコピー」：その語句と元の英文をまとめた質問文をコピーします。

ChatGPTなどへ自分で貼り付ける方式です。コピーだけでは外部AIへ送信せず、保存データも変更しません。自動コピーが失敗した場合は、手動コピー用の欄が表示されます。

### 小窓の表示と保存

四隅のドラッグでサイズを調整できます。通常の最小サイズは400×400pxで、小さな画面では画面内に収まる大きさを優先します。「ワイド」で英文と訳を左右に並べられます。

メニューから文字サイズ・サイズリセットを操作できます。位置・サイズ・文字サイズは端末ごとにChromeへ記憶します。サイズリセットでは訳やメモを消しません。×で閉じられ、Escはメニューが開いていればメニューを、それ以外では小窓を閉じます。

訳・メモは自動保存ではありません。「未保存」「保存済み」「保存後の変更あり」を確認してください。小窓で保存後に編集して再保存すると、別の英文記録が追加されます。既存の英文を修正する場合は「保存内容 → 英文 → 編集」を使います。

## 単語・熟語を復習する

1. 「今日の復習」で表現の意味を思い出します。
2. 「答えを見る」で、意味・コアイメージ・メモ・例文を確認します。
3. 「忘れた」「あいまい」「覚えていた」を選びます。

結果に応じて次の復習予定と学習状態が更新されます。「未学習・学習中・覚えた」の状態や登場回数は「保存内容 → 単語・熟語」からも確認できます。

## 英文を並び替えて復習する

「保存内容 → 英文」で「最新順・ランダム・復習シャッフル」を選べます。復習シャッフルでは、未復習・最後の復習から時間がたった英文を出やすくします。

一覧では英文と日本語訳をそのまま表示し、長い説明・メモだけ先頭3行にまとめます。「続きを読む」で全文を開き、「折りたたむ」で戻せます。短いメモには開閉ボタンを表示しません。1件ずつの復習では「訳・メモを見る」で全文を表示します。表示を折りたたんでも保存内容は変わりません。

英文ごとの「復習の出やすさ」は「少なめ・通常・多め」から選びます。少なめは、すでに理解できる英文や似た英文を十分読んだときに使えます。少なめでも候補から完全には除外しません。設定変更や編集では現在の並びを動かさず、次のシャッフルから反映します。

「英文を10件復習」では、5・10・20件から件数を選び、全英文から重み付きで選んだ英文を重複なしで1件ずつ読み直せます。

1. 英文を読み、必要なら「訳・メモを見る」を押します。
2. 「読み直した」で復習日時・回数を保存し、次の英文へ進みます。
3. 「今回はスキップ」では復習記録を付けません。

保存日・編集日は復習日として扱いません。通信失敗後に同じ操作を再試行しても二重に数えない仕組みがあります。英文の復習だけで、関連する単語を「覚えた」へ変更しません。

履歴・出やすさはPCとスマホで共通です。途中の位置はページ内の画面切り替えでは保持しますが、ページを再読み込みすると新しい回になります。

## 意味・コアイメージ・メモを残す

単語・熟語には意味・コアイメージ・自由メモを保存できます。「保存内容 → 学習メモ → 英文・語句のメモ」では、コアイメージ・語句メモ・英文メモを一覧で確認できます。英文・語句の横断検索、文字サイズ切り替え、語句の状態・メモあり・登場回数による絞り込みも使えます。

同じ語句を英文と一緒に再登録した場合は、語句の記録を重複させず、登場回数・重要度を増やします。英文そのものは別の記録として保存します。

- 「追記」：元の説明を残し、区切り線と【追記】を付けて下に追加します。空欄や同じ説明は追加しません。
- 「編集」：現在の欄全体を修正します。追記した説明を直す場合にも使います。

説明だけの追記では、登場回数・学習状態・復習予定を変えません。[追記のガイド](vocabulary-append-guide.md)も参照してください。

## 知識ノートで調べものをまとめる

新しく書く場合は「入力して保存 → 知識ノート」を選び、タイトルと本文を入力します。文法の整理や表現の比較など、日本語だけでも保存でき、例文や訳は必須ではありません。

読む・編集する場合は「保存内容 → 学習メモ → 知識ノート」を開きます。一覧の「ノートを書く」も同じ入力画面への近道です。保存後の「保存したノートを見る」で、保存したノートを直接開けます。

- 「使い分け・文法の整理・調べもの」のひな形を任意で使えます。「ひな形を本文に追加」は入力済みの内容を消さず、末尾に見出しを追加します。
- 「あとで確認する」は知識ノート専用の目印です。確認待ちだけに絞り込み、外すこともできます。
- 一覧には本文の冒頭と更新日を表示します。「ノートを読む」で全文を開き、「ノートを編集」で修正します。タイトル・本文の検索にも対応します。知識ノートの検索はこの画面で行います。
- 「ノートを保存」でクラウドへ保存します。新規作成は保存成功後に入力欄を空にして、続けて書けます。保存失敗時は入力を残します。英文・訳と知識ノートの切り替えや、別画面への移動でもそれぞれの下書きは残りますが、ページの再読み込み後の自動復元には対応しません。

知識ノートは同じアカウントでPC・スマホから利用できます。保存・本文の修正は学習記録に入り、読み直した後は「読み返した」で復習を記録できます。単語の登録・学習状態・復習予定、既存の英文メモ・コアイメージは変更しません。知識ノート自体はAI・翻訳APIやCodex整理には自動送信しません。関連英文へのリンクや分類タグは未対応です。

## 自分で英文と訳を入力する

「入力して保存」はPC・スマホで使えます。「英文・訳」を選ぶと、英文と日本語訳を自分で入力・貼り付け、使う場面のメモ、入手元、任意の参照URL、必要な語句も登録できます。「知識ノート」と切り替えても入力内容は残ります。

「英語を日本語に翻訳」「日本語を英語に翻訳」を押したときだけGoogle翻訳を使います。保存ボタンでは翻訳もAIも呼びません。語句の意味は手入力です。英文全体を一つのフレーズとして追加することもできます。

保存に成功したときだけ入力欄を空にし、続けて別の英文を登録できます。失敗時は入力を残します。画面切り替えでは下書きを保持しますが、ページ再読み込み後の自動復元には対応していません。

## 英作文を練習する

「メニュー → 英作文の練習」から開きます。

1. 保存済みの表現を1〜3個選び、用意されたお題で2〜4文を書きます。
2. 「作文と指示文をコピー」でChatGPTなどへ自分で貼り付けます。
3. 返ってきた添削・修正文をアプリに貼り付けて保存します。

表現に合うお題が欲しい場合は「お題作成用の指示文をコピー」も使えます。AIへ渡す参考情報は選択した表現に絞り、意味は各250文字・コアイメージは各600文字までに制限します。

作文は入手元「英作文」として保存します。お題・対象表現・添削は区切り付きのメモに残し、保存後の添削追加は同じ記録を更新します。元の語句の説明・登場回数・復習予定は変えません。日本語訳は任意です。

この画面からAI・翻訳APIは呼びません。ただし、外部AIへ貼り付けたときはそのサービスの利用枠を使います。下書きは自動保存ではありません。

## 定期整理

「メニュー → 整理」で、未整理・追加編集分だけを件数・文字数の上限付きでJSONに書き出します。Codexなどへ渡し、返ってきた結果JSONを読み込み、候補を採用・見送りしてから保存します。読み込むのは元の書き出しJSONではなく、整理後の結果JSONです。

元のメモは残します。表示されるトークン数は目安で、実際の消費量を保証するものではありません。[整理のルールと結果形式](organization-guide.md)を参照してください。

## 学習記録カレンダー

「今日の復習」には、最近8週間の学習記録カレンダーがあります。日本時間の日付で、次の行動を記録します。

- 保存・追記：英文・語句・知識ノートの保存、意味・コアイメージ・メモの修正、英作文や添削の保存、整理で採用して登録した熟語リスト。同時に保存した英文と語句はそれぞれ対象です。
- 復習：単語の回答（「忘れた」も含む）、5・10・20件の英文復習、通常の英文一覧の「読み直した」、学習メモや知識ノートの「読み返した」。10件を完了する前でも、保存済みの復習は1件ずつ反映します。
- 調べもの：成功した翻訳・AI解説。同じ日の候補語の自動翻訳などで水増ししないよう、1日1件です。翻訳自体が成功しても記録の通信だけ失敗することがあり、その場合は記録されません。拡張機能の端末内翻訳も、ログイン・クラウド接続できる場合に記録します。

同じ対象・同じ行動は1日1件とし、保存と復習は別に数えます。画面を開くだけ、コピーだけ、スキップ、目印や出やすさの変更は対象外です。単語の学習状態・復習予定は学習記録のために変更しません。

保存・追記・復習の記録はSupabase側で付き、PC・スマホ・拡張機能で共通です。記録自体にAI・翻訳の追加呼び出しはありません。初回は[設定ガイド](setup.md)の追加SQLが必要です。未適用でも既存履歴による表示は残ります。

過去の英文・語句・ノート・熟語リストの作成と、語句・英文の復習は、残っている日時付きの履歴から復元します。履歴のない過去の編集・ノートの読み返し・翻訳は推測しません。新しい学習記録には本文・訳・URLは保存せず、種類・対象ID・日時だけを残します。内容を後で削除しても、記録済みの学習履歴は残ります。色は英語力の点数ではなく、英語に触れた記録です。
