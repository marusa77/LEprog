# 単語の説明を追記するための準備

## Supabaseで1回だけ行う作業

1. 今使っているPhraseNestのSupabaseプロジェクトを開きます。
2. SQL Editorで新しいクエリを開きます。
3. `supabase/migrations/0004_append_vocabulary_details.sql` の全文を貼り付けます。
4. Runで実行します。Successが出れば準備完了です。

このSQLは保存用の処理を追加・更新するものです。既存の単語・英文・メモを書き換えたり、テーブルや記録を削除したりしません。途中で確認処理が失敗すれば、今回の処理変更を取り消します。以前の0001〜0003は実行し直さないでください。

## 使い方

- 公開ページの「保存内容」→「単語・熟語」→対象の単語の「追記」を開きます。
- 追加したい意味・コアイメージ・メモだけ入力し、「追記を保存」を押します。どれか1つだけでも構いません。
- 元の説明を残して、その下に区切り線と【追記】を付けて追加します。
- 空欄は無視し、すでにある説明と同じものは追加しません。改行・連続スペースだけが違う場合も同じ説明として扱います。
- 同じ単語をRedditの小窓や「入力して保存」から再登録した場合も、新しい説明は同じ方法で追記します。英文は従来どおり別の記録として保存されます。
- 「追記」だけでは登場回数・学習状態・復習予定は変えません。英文と一緒に再登録した場合は、従来どおり登場回数・重要度が上がります。

保存された説明は、単語帳・学習メモ・復習画面で確認できます。

## 修正・削除したい場合

「編集」は欄全体の修正です。追加した説明を直したり削除したりする場合は「編集」を使います。区切り線と【追記】もテキストとして保存されているため、編集画面で変更できます。

## 確認例

1. 既存のコアイメージがある単語を選び、内容を確認します。
2. 「追記」で別のコアイメージを追加します。
3. 元の説明が残り、下に区切り付きで新しい説明があるか確認します。
4. 同じ説明をもう一度「追記」し、説明が増えないことを確認します。

SQL未実行の間は「追記」ボタンで準備が必要と表示します。従来の再登録は元の説明を保持するだけで、新しい説明は追加されません。
